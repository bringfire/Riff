AEC Tech Hackathon · Riff

Reasoning becomes reviewable.

Chirp produces structured reasoning on the Grasshopper canvas. The broker compiles and publishes an immutable snapshot so people can inspect every node, record a decision, and hand one authoritative artifact back to the external LLM agent.

01 · Chirp

Structured source reasoning

Each node contributes a complete ReviewPacket with stable identity, role, rationale, assumptions, parameters, and provenance.

02 · Riff

Adaptive trusted presentation

Riff reads the complete snapshot, adds grounded annotations, and arranges trusted UI templates without rewriting the source.

03 · Human

Per-node decisions

A reviewer accepts, rejects, or requests a correction with attribution. Human state stays separate from Chirp reasoning and Riff analysis.

04 · Export

Review Matrix

The current canvas state, immutable reasoning, Riff annotations, and human decisions are exported as one node-ordered JSON document.

Human-controlled handoff: Riff does not modify Grasshopper, resubmit Chirp nodes, or run an automatic approval loop. A person exports the Review Matrix; the external LLM agent may then author tailored correction panels and place them back on the canvas.
